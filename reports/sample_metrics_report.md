# Sample Metrics Report

This is the expected shape of the metrics summary generated by:

```bash
make run-sample
```

Sample run configuration:

- Dataset: `data/ran_kpi_sample.csv`
- Cell: `CELL_001`
- Target KPI: `prb_dl_util`
- Model: `ridge_linear`
- Forecast horizon: `24`
- Lag features: `1,2,3,6,12`

Generated metrics are written to:

- `reports/forecast_examples/latest/metrics.json`
- `reports/forecast_examples/latest/metrics_summary.md`

The exact values may change when the sample telemetry or feature set changes, but the summary must include RMSE, MAE, and MAPE from a temporal hold-out split.
