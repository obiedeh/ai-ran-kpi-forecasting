# Reports

Report artifacts are generated by the CLI and are intended to be reproducible from source-controlled sample telemetry.

Run the sample workflow:

```bash
make run-sample
```

Expected files in `reports/forecast_examples/latest/`:

- `prb_dl_util_forecast.csv`: forward KPI forecast with timestamp, step, and predicted value.
- `prb_dl_util_holdout.csv`: hold-out actuals and predictions.
- `metrics.json`: machine-readable RMSE, MAE, and MAPE.
- `metrics_summary.md`: human-readable metrics summary.
- `prb_dl_util_forecast.svg`: KPI plot for actuals, hold-out prediction, and forward forecast.
- `feature_importance.csv`: model coefficient importance.

The reports are offline artifacts. They are suitable for engineering review, CI smoke checks, and static publication, but they are not live RAN integrations.
