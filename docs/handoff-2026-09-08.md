## Where this repo sits

This is the telecom-side end of the edge story on the profile. The same
pipeline shape (typed records, no-leakage lag features, small model,
human-reviewed decision) runs on network flows in
[jetson-edge-ai-security](https://github.com/obiedeh/jetson-edge-ai-security)
and on radio KPIs here. The security repo has a measured Jetson AGX Thor
inference benchmark and a measured thread-pool power finding; this repo has
neither yet. Its first device measurement is the next step, and it borrows
the security repo's harness rather than writing its own.

## Claims that are defensible now

1. A reproducible Non-RT RIC rApp pattern with typed contracts, no-leakage
   temporal evaluation, and advisory-only policy output.
2. On the sample data the linear model wins and the MLP loses badly; the
   repo shows that rather than hiding it.
3. The models are exportable to ONNX with numerical parity, so the same
   edge inference harness can measure them.

Nothing about forecast accuracy on real RAN telemetry, and nothing about
device cost, until the artifacts in the work order exist.
